# Credit Scoring Model

## Project Overview
This project predicts creditworthiness using machine learning algorithms and historical German Credit data.

## Dataset
- Dataset: UCI German Credit Dataset
- Total Records: 1000
- Features: 20

## Machine Learning Algorithms
1. Logistic Regression
2. Decision Tree
3. Random Forest

## Data Preprocessing
- Handling missing values
- Encoding categorical features
- Scaling numerical features
- Train-test split

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

## Best Model
The best-performing model was selected based on ROC-AUC score and saved as `credit_scoring_model.pkl`.

## Project Files
- `credit_scoring_model.pkl` – Trained machine learning pipeline
- `credit_scoring_results.csv` – Model performance comparison

## Tools and Technologies
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Joblib, Google Colab

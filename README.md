# CodeAlpha_Credit_Scoring_Model

## Project Overview
This project focuses on predicting an individual's creditworthiness using Machine Learning techniques.

## Objective
To build and evaluate machine learning models that predict creditworthiness based on financial data.

## Dataset
- Dataset: German Credit Dataset
- Number of records: 1000
- Number of features: 20

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning
- Google Colab

## Machine Learning Models
The following models were trained and compared:
1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier

## Model Performance

| Model | Accuracy |
|---|---:|
| Logistic Regression | 78% |
| Decision Tree | 63% |
| Random Forest | 74% |

Best-performing model: Logistic Regression

ROC-AUC Score: 0.804

## Project Workflow
1. Import required libraries.
2. Load the German Credit Dataset.
3. Preprocess the data.
4. Split the dataset into training and testing sets.
5. Train three machine learning models.
6. Evaluate and compare model performance.
7. Select the best-performing model.
8. Save the trained model and prediction results.

## Project Files
- `CodeAlpha_Credit_Scoring_Model.ipynb` – Complete project code.
- `credit_scoring_model.pkl` – Saved machine learning model.
- `credit_scoring_results.csv` – Model prediction results.
- `README.md` – Project documentation.

## Limitations
- The model's performance depends on the dataset used.
- Further testing is required before real-world use.
- Fairness and reliability should be evaluated before using predictions for financial decisions.
